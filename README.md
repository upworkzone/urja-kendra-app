# URJA KENDRA — Fresh Android Starter

**Tagline:** ऊर्जा बनाओ, ऊर्जा बचाओ, पैसे कमाओ...

This is a clean Android project starter for the approved Option A scope: learning, enrolment, and career pathways. Shopping/checkout for physical products is deliberately excluded.

## Current milestone
- Kotlin + Jetpack Compose shell
- English/Hindi UI labels with a simple in-app language toggle
- Home, Courses, My Learning, Careers, Profile tabs
- Mock course catalogue and career pathways
- No real authentication, backend, payments, or certificate issuance yet

## Requirements
- Android Studio with a JDK 17 toolchain
- Android SDK Platform 35
- Gradle wrapper should be generated by Android Studio if not present

## Open and run
1. Open this directory in Android Studio.
2. Allow Gradle sync and install the required SDK if prompted.
3. If Android Studio requests a Gradle wrapper, choose its compatible recommended version.
4. Run the `app` configuration on an emulator or connected Android device.

## Important
This is a starter source project, not a signed APK and not yet production-ready. The initial dependencies and plugin versions are pinned as a starting point; confirm compatibility through Gradle sync in your chosen Android Studio version. Before public release, implement a backend, secure mobile OTP verification, course content APIs, server-side assessment scoring, approved certificate rules, privacy/terms, and security tests.
